Under the hood

Two ways an answer can grow.

Path A

Rooted in the dataset

Your question is embedded and matched against real crop records — nitrogen, phosphorus, potassium, temperature, humidity, pH and rainfall — using semantic search over the local vector store.

  1. Question embedded with MiniLM
  2. Nearest growing conditions retrieved from ChromaDB
  3. Gemini reasons only over that retrieved context
Path B

Branches out to the web

Questions outside the dataset — prices, news, general agronomy — are routed to live Google Search grounding, with a DuckDuckGo fallback if that's unavailable.

  1. Router decides DATASET vs WEB
  2. Gemini + Search grounding fetches current info
  3. Falls back to free web search if quota is hit
